Audit log

Each entry carries a timestamp, the rule version in force, and a hash of the case inputs. In production this persists to an append-only store the firm controls.

Data handling in production

  • All extraction, prompt chains, and rules evaluation run server-side on infrastructure the firm controls. No model keys, prompts, or business logic ship client-side.
  • LLM calls use zero-retention API terms; client documents are not used for model training.
  • PII/VIN redaction available at ingestion; append-only audit log retained per firm policy.

Honesty notes

  • All names, vehicles, dealers, VINs, and records are fictional.
  • Thresholds reference the Song-Beverly Consumer Warranty Act, Civ. Code § 1793.2 et seq., and the Tanner Consumer Protection Act presumption, Civ. Code § 1793.22, as illustrative starting points requiring attorney validation.
  • Day-counting and attempt-grouping conventions are simplifications marked for counsel review. Rodriguez v. FCA US LLC (Cal. 2024) screening asks a question; it does not decide coverage.
  • Built by Andre C as a technical demonstration. Nothing here is legal advice.
